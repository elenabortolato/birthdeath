# Controlled precision-matrix experiments

This project separates the estimator from the data-generating mechanism. It can
simulate observations directly from fixed or time-varying precision matrices,
including matrices that are not generated by the fitted low-rank model.

## Files

- `BirthDeathGraphicalModels.jl`: estimator module, cleaned so importing it does
  not automatically run an example.
- `ControlledPrecisionExperiments.jl`: scenario constructors, direct Gaussian
  sampling from precision matrices, diagnostics, and replicate runners.


* **`README.md`**: Provides an overview of the repository and instructions for reproducing the experiments.
* **`prior_plot.R`**: Contains the code used to generate plots of the prior distributions.
* **`Experiment_piecewise/`**: Contains the simulation experiments for the piecewise model.

  * **`piecewise_5/`**: Experiments for the piecewise setting with 5 variables.
  * **`piecewise_50/`**: Experiments for the piecewise setting with 50 variables.
* **`Experiment_birthdeath/`**: Contains the simulation experiments for the birth–death model.

  * **`birthdeath_5/`**: Experiments for the birth–death setting with 5 variables.
  * **`birthdeath_50/`**: Experiments for the birth–death setting with 50 variables.
* **`sensitivity_piecewise/`**: Contains the sensitivity analyses for the piecewise model.
